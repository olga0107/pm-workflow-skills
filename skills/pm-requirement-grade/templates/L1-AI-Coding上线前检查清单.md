## 1. 分级与范围

- [ ] 已填写需求分级卡，最终等级为 L1。
- [ ] 未命中 L3 红线，且没有待确认高风险项。
- [ ] 变更文件在白名单范围内。
- [ ] 没有扩大需求范围或顺手修改无关问题。
- [ ] 若有不确定项，已升级给研发/负责人确认。

## 2. 代码与安全

- [ ] 没有新增依赖、SDK、生产域名、WebView/外链。
- [ ] 没有新增或修改后端写入、状态机、数据迁移/补偿。
- [ ] 没有修改资金/交易、登录/授权/隐私/token、权益/资产、核心链路、请求封装、全局配置。
- [ ] 没有硬编码 token、secret、手机号、用户 ID、生产凭证。
- [ ] 没有 mock、测试用户 ID、测试接口或调试开关进入生产代码。
- [ ] 没有吞异常导致假成功，没有隐藏错误提示或失败状态。
- [ ] 没有 console/debug 日志输出敏感信息。
- [ ] 已人工审查 AI diff，确认无越界修改。

## 3. 验证

- [ ] 项目构建命令通过：`[填写命令]`。
- [ ] 变更文件 lint/format/typecheck 通过，或已记录项目暂无脚本。
- [ ] 变更页面/功能在目标运行环境中可打开。
- [ ] 已测主路径、返回、刷新、空态、加载失败。
- [ ] 已测不同登录/权限/状态（如适用）。
- [ ] 已测主要机型/字号下不严重错位。
- [ ] 已留截图或录屏。

## 4. 发布与回滚

- [ ] 有明确回滚方式：revert / 关闭入口 / 配置恢复 / 发版回滚。
- [ ] 上线后观察错误、投诉和关键指标。
- [ ] 明确观察责任人和观察周期。
