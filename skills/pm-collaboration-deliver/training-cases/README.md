# Training Cases

本目录收录 `pm-workflow-skills` 的真实训练案例。案例不是模板，也不是某个 Skill 已经有效的证明，而是用于：

- 展示真实产品需求如何从模糊输入推进到正式交付；
- 记录关键判断、失败方式、人工纠偏和最终方法；
- 将案例经验转化为可迁移的 Skill 设计原则；
- 为后续版本提供可重跑的回归问题。

## 收录标准

每个案例应回答：

1. 最初面对的真实问题和输入是什么；
2. 过程中发生了哪些关键转折；
3. AI 做对了什么、做错了什么；
4. 产品角色和其他参与方作出了哪些关键判断；
5. 最终形成了什么交付物；
6. 哪些经验可以进入通用 Skill，哪些只能保留为案例特例；
7. 后续如何用该案例验证 Skill 是否进步。

案例正文应可独立阅读，不依赖作者本机路径、私人聊天记录或内部系统权限。涉及真实业务时，应只保留理解方法所需的信息，并在进入可公开仓库前完成必要脱敏。
